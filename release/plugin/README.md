*About*

This modifier can resize an object using dimensional values instead of scale factors.

For example, let's assume you have an out-of-scale Chair model. Instead of "scaling it until it fits, you can match it to real dimensions (i.e., 0.50 x 0.50 x .70 mts.)

*How to use*

Look for "Resizer" in the command panel modifier list.
Use the XYZ spinners (or Length Width and Height) to change the dimensions of an object.
If "Keep proportion" is checked, the values are constrained to maintain the original object proportions.
Use "Link proportions" to simulate non-uniform by plane (XY, XZ, YZ) scale.
